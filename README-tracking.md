# Логирование посещений и уведомления в Telegram

Модуль встроен в `server.js` и `app.js` этого проекта. Внешних зависимостей нет.

## Что происходит при визите

1. `app.js` один раз за сессию отправляет `POST /track` со своим адресом, referrer,
   размером экрана, языком и часовым поясом.
2. Сервер определяет IP (с учётом прокси-заголовков) и User-Agent, сразу отвечает `204`,
   а дальше в фоне: уточняет страну/город по IP и дописывает строку в `visits.jsonl`.
3. В Telegram уходит сообщение: время, гео, IP, страница, устройство/ОС, источник.

Строка визита в `visits.jsonl`:

```json
{"ts":"2026-11-20 09:15:02","ip":"203.0.113.7","path":"/","ua":"Mozilla/5.0 ...","ref":"https://...","screen":"1920x1080","lang":"ru-RU","tz":"Europe/Moscow","country":"Россия","city":"Москва"}
```

## Настройка

Заполните `.env` рядом с `server.js` (файл уже создан, значения пустые):

```dotenv
TELEGRAM_BOT_TOKEN=123456789:AA...   # токен бота из @BotFather
TELEGRAM_CHAT_ID=123456789           # ID чата/канала из @userinfobot
STATS_KEY=придумайте-длинный-ключ    # доступ к /stats
```

- Токен: в Telegram напишите `@BotFather` → `/newbot` → получите токен.
- Chat ID: напишите боту любое сообщение, затем узнайте ID у `@userinfobot`
  (для канала — добавьте бота администратором и используйте `-100...`).
- Без токена уведомления выключены, но визиты всё равно пишутся в файл.

На сервере VibeCode те же три переменные задаются в окружении деплоя —
значения из окружения имеют приоритет над `.env`. Файл `.env` в репозиторий и в
публикацию класть не нужно: он содержит секреты.

## Где лежат данные

`DATA_DIR` → `/data` (том, переживающий передеплой) → `./data` рядом с кодом.
Первая доступная для записи папка из этого списка. На сервере это `/data/visits.jsonl`.

## Страница статистики

`https://<адрес-приложения>/stats?key=<STATS_KEY>` — последние 500 визитов.
Без заданного `STATS_KEY` или с неверным ключом отвечает `404`. Страница закрыта от
индексации и выводит все поля с экранированием HTML.

## Защитные меры

- `/track` принимает только `POST`, только JSON до 4 КБ, только с того же `Origin`.
- Не больше 30 событий в минуту с одного IP (иначе `429`).
- Уведомление по одному IP не чаще раза в 60 секунд — перезагрузка страницы не спамит.
- Гео-запрос уходит только на валидный публичный IPv4; приватные адреса не геолоцируются.
- Токен Telegram берётся из окружения и никогда не пишется в логи.
