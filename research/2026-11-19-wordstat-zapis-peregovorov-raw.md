# Wordstat raw data — «запись переговоров» / транскрибация (product discovery)

- **Дата измерения:** 2026-11-19
- **Метод:** управляемый браузер (ZCode in-app browser), авторизованный веб-интерфейс wordstat.yandex.ru (без официального API). Вход в Яндекс-аккаунт уже выполнен (сессия сохранена), автоматизация логина/капчи не использовалась.
- **URL-паттерн (воспроизводимость):**
  - Тоталы: `https://wordstat.yandex.ru/?region=all&view=table&words=<encodeURIComponent(запрос)>`
  - История: `...&view=graph` (регионы: `region=213` Москва, `region=2` Санкт-Петербург)
- **Окна измерения (по каждому запросу отдельно, т.к. Wordstat возвращал разные окна):**
  - Окно A: `13.10.2026 – 11.11.2026` (≈30 дней, публикация с лагом ~1 месяц)
  - Окно B: `18.10.2026 – 18.11.2026` (сдвинутое окно — исключение, помечено)
- Статус сервиса: баннеры не мешали (навигация через URL-параметры, без кликов).

## 4. Расчётные оценки (ОЦЕНКА)

- **ОЦЕНКА** (метод: сумма Яндекса+Google ~ паритет): широкая категория «транскрибация + расшифровка + ии для совещаний + запись звонков/разговоров» ≈ 47 478 + 882 + 470 + 638 + 424 + 1 344 ≈ **51–55 тыс. показов/мес в Яндексе** на всю РФ; с Google-поиском и аналогами запросов («расшифровка аудио в текст» и пр.) совокупный поисковый спрос категории оценивается в **80–150 тыс. запросов/мес**. Это показы, не уникальные пользователи и не покупатели.
- **Сезонность (ОЦЕНКА по истории):** спады июль–август (−20–30% от среднегодового), пики сентябрь–октябрь и март–апрель.
- **Коммерческие маркеры низкие:** «купить систему записи разговоров» 20/мес, «заказать транскрибацию» 13/мес, «анализ звонков отдел продаж» 26/мес — прямой поисковый спрос на покупку слабый; спрос выражен через обучение/инструмент («онлайн», «бесплатно», «приложение»), а не через «купить».

## 5. Ограничения

1. `view=table` — скользящее ~30-дневное окно с лагом публикации ~1 месяц; окна у части запросов сдвинуты (окно B 18.10–18.11) — сравнивайте с осторожностью.
2. Показы ≠ уникальные пользователи ≠ платящие клиенты; нельзя умножать на конверсию.
3. «запись переговоров» и «расшифровка телефонных разговоров» загрязнены юридическим контекстом (УПК РФ, «для суда») — business-интент внутри них меньше тотала.
4. Окт 2026 в истории «запись совещаний» не опубликован (0) — не нулевой спрос.
5. Таблица связанных запросов для «tech note» не отрисовалась за 2 попытки; доступен только тотал 105.
6. Третья колонка «Доля от всех запросов, %» в «Динамике» при чтении ячеек по отдельности корректно исключена (риск склейки учтён по методике).
